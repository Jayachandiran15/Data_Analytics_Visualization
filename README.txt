CS4503: DATA ANALYTICS AND VISUALIZATION - Lab Manual
Compiled Programs and Outputs
=======================================================

Each folder below contains two files:
  - code.py     : the program source code
  - output.txt  : the corresponding output / result (figures noted as [Figure: ...])

01_Installation             - Installing & exploring NumPy, SciPy, Jupyter, Statsmodels,
                               Pandas, Matplotlib, Seaborn, Plotly, Bokeh
02A_NumPy_Arrays             - NumPy array operations & manipulations
02B_Pandas_DataFrame          - Pandas DataFrame operations
02C_Reading_Data              - Reading data from text files, Excel, and the web
02D_Iris_Descriptive           - Descriptive analytics on the Iris dataset
03A_Univariate_Analysis        - Univariate statistical analysis (Diabetes datasets)
03B_Bivariate_Regression        - Bivariate analysis: Linear & Logistic Regression
03C_Multiple_Regression          - Multiple regression analysis
03D_Comparison_Datasets           - Comparison of UCI vs Pima analysis results
04A_Normal_Curves                  - Normal curve visualization
04B_Ztest                            - Z-test hypothesis testing
04C_Ttest                             - T-test hypothesis testing
04D_ANOVA                              - ANOVA hypothesis testing
05A_Linear_Model                        - Building & validating linear regression models
05B_Logistic_Model                       - Building & validating logistic regression models
05C_TimeSeries_Analysis                   - Time series analysis with ARIMA forecasting

Source: DAV_manual_UPDATED.pdf (Chennai Institute of Technology)
